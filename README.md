## About This Challenge

The 100 Days of C Programming Challenge is a structured learning initiative aimed at improving programming fundamentals through daily practice. This challenge focuses on solving C programming problems consistently and maintaining progress using Git and GitHub.

The repository contains solutions, code snippets, and practice exercises completed throughout the challenge. Each day includes either a new concept or a problem that strengthens logic, understanding of C syntax, and overall problem-solving ability.

---

## Goals of the Challenge

* Build a habit of consistent coding
* Strengthen core C programming concepts
* Improve logic building and problem-solving skills
* Apply Git and GitHub for regular version control
* Maintain a public record of daily programming practice

---

## Repository Structure

* Each day is organized in separate C program files
* File naming format: `dayXX_Y.c` where XX = day number, Y = question number
* Problems include arrays, matrices, strings, searching, sorting, and more
